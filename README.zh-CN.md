# 🧠 prompt-promote

**乱进，忠出（Messy in, faithful out）。** 一个 Agent skill：在模型内部把用户脏提示词加工为结构化标准提示词——然后忠实执行。单程、近零开销。

**[English](README.md) | [简体中文](README.zh-CN.md)** · v0.1.1 · [MIT](LICENSE)

---

## 痛点

真实世界的提示词是脏的：半句话、一大段噪声、一行塞三个任务、缺上下文——约束隐含其中，却从不言明。

代价不是风格，而是**意图**：

- *"帮我优化简历"* → 模型编造了一个你没做过的项目
- *"写封请假邮件"* → 模型把你闲聊里的"奶奶身体不好"当成了请假理由
- *"13 人排班，别背靠背休息"* → 模型漏掉了周日→周一的边界

一个错误假设，就能毁掉一份简历、一封邮件、一张排班表。prompt-promote 就是为了防止这种事发生。

## 它做什么

agent 收到提示词时，prompt-promote 在后台静默地：

1. **解析** 意图、约束、事实锚点、依赖
2. **分类** 任务类型（写作 / 代码 / 分析 / 翻译 / 其他）
3. **加工** 为 8 字段结构化提示词（角色 / 任务 / 上下文 / 输入 / 约束 / 输出格式 / 示例 / 评判标准）
4. **自检** 四问——意图覆盖？范围不超？约束不丢？事实不虚构？
5. **执行** ——加工后的提示词从不出现在回复里

**你看到的是结果，不是机器内部。** 单程、无额外 API 往返（约 +10–50 token，+0.1–0.5 秒）。

## 为什么值得装

- **🎯 忠实意图** —— "可乐"就是可乐，不会变成"饮料"。你要的全覆盖，不要的一点不加。
- **🚫 防编造** —— 历史闲聊不是事实依据；改写材料不添加来源外信息；缺数据用占位符（`XX`）或反问，绝不编数字。
- **✅ 约束自检** —— 隐式约束被显式化并逐条验证：词序、语气、格式，连排班表的跨周边界都查。
- **⚡ 近零成本** —— 单程加工，自检嵌入同一次推理，不加 API 往返。
- **🌐 双语字段、内容跟随用户语言** —— 字段名中英双写，内容永远用用户的语言。
- **🔧 Debug 模式** —— 设置环境变量可查看内部加工结果：
  - PowerShell：`$env:PROMPT_PROMOTE_DEBUG=1`
  - CMD：`set PROMPT_PROMOTE_DEBUG=1`
  - bash：`export PROMPT_PROMOTE_DEBUG=1`

## 数据说话，不靠嘴说

40 条外部用例（IFEval / FollowBench / WildBench / TruthfulQA），独立 subagent 生成输出 + 机器/checklist 打分：

| 场景 | 基线 | 加工后 |
|---|---|---|
| 干净会话（13 条种子） | 4.85 | — |
| 脏会话（13 条种子） | 4.65 | **4.92** |
| 真实脏提示词 · WildBench（16 条） | 4.78 | **4.94** |
| 外部总体（40 条） | 4.86 | **4.96** |

40 条 **0 回退**。触发这个项目的两个真实失败——编造简历项目、虚构请假理由——已被修复并通过回归。用例 B9（13 人排班表）通过程序化校验，包括基线漏掉的跨周边界检查。

方法学说明：以上数字采用独立输出 + 机器/checklist 打分口径。早期自评 pilot（+1.11）高估，完整说明见 `tests/overall-report.md`。

## 快速开始

```bash
# 把 skill 复制到 agent 的 skills 目录
cp -r prompt-promote <agent>/skills/prompt-promote
```

就这样——无需触发词、无需包装。agent 会自动对每个任务类请求应用。
