# 种子用例（Seed Cases）

> 用途：端到端评测。每条用例 = 脏提示词 + 理想结果 + 隐藏陷阱。
> 用法：不加工直接跑（基线）vs 加工后跑（skill），对比结果质量。
> 评分思路：理想结果达成度 + 陷阱是否踩中。

## 运行说明（哪些用例需要附件）

基线测试时以下用例需要补齐输入材料：
- C02：附一份销售数据表（运行前提供）
- C05：需一个真实 PDF 文件（运行前提供或替换为等价任务）
- C06：需会话历史（运行前构造）
- C08：需正则表达式 + 目标文本（运行前提供）
- C10：需一段含 bug 的代码（运行前提供）
- C13：URL 为示例域名（example.com），验证"无法访问时是否诚实说明"

## 一、我拟的典型用例（8 条）

### C01 目标模糊
- **原始提示词**：`帮我写点东西`
- **理想结果**：识别目标缺失 → 一次性反问明确（写什么/给谁/什么形式），或给出合理默认并说明假设后产出
- **隐藏陷阱**：直接产出泛泛而谈的套话，假装完成了任务

### C02 无输出格式
- **原始提示词**：`分析一下这几天的销售数据`（附数据表）
- **理想结果**：输出结构化分析（趋势 / 异常 / 建议），按明确格式组织
- **隐藏陷阱**：只给一段散文式总结，无结构、无重点

### C03 隐含约束遗漏
- **原始提示词**：`写个 Python 脚本下载这个网页的图片，注意不要用第三方库`
- **理想结果**：只用标准库（urllib 等）实现
- **隐藏陷阱**：顺手用了 requests / bs4（违反约束）

### C04 超范围扩展（汉堡问题）
- **原始提示词**：`帮我写一封道歉邮件给客户`
- **理想结果**：只完成道歉邮件，不添加额外内容/建议
- **隐藏陷阱**：主动加"顺便帮你起草一份赔偿方案"或"建议再发个优惠券"

### C05 冗余噪声
- **原始提示词**：大段情绪化背景 + 夹在中间的一个真实需求（如"……总之帮我把那个 PDF 转成 Word，别的不用管"）
- **理想结果**：忽略噪声，只执行真实需求
- **隐藏陷阱**：被噪声带偏，把情绪话当需求，或额外做多余的事

### C06 上下文缺失（指代不明）
- **原始提示词**：`把这个改一下`（无指代对象）
- **理想结果**：识别指代缺失 → 反问，或基于会话历史合理推断并说明假设
- **隐藏陷阱**：凭空瞎猜，改了个不存在的东西

### C07 多任务混装
- **原始提示词**：`帮我写个活动文案，顺便看看我简历行不行，再推荐两本关于沟通的书`
- **理想结果**：拆成三个子任务，依次完成，各自有清晰输出
- **隐藏陷阱**：只做了第一个任务，或把三件事混成一团

### C08 技术隐含假设
- **原始提示词**：`这个正则匹配不到我要的，帮我看看`（附正则与目标文本；用户是开发者）
- **理想结果**：理解技术上下文，定位正则问题并修复
- **隐藏陷阱**：把"正则"当普通文本，输出无关建议，或解释过度

## 二、用户真实用例（5 条）

### C09 简历优化（用户真实）
- **原始提示词**：`帮我优化一下我的简历，量化我的项目业绩，尽量抓住面试官的痛点进行分析优化，同时保持简历格式，将简历内容保持在一页`
- **理想结果**：输出优化好的简历，内容符合要求且**真实可信（不虚构）**，格式与之前保持一致
- **隐藏陷阱**：编造未参与的项目/不了解的知识；更换简历模板；格式错乱、行不对齐
- **关键约束**：内容真实不虚构、保持原格式、一页以内

### C10 修复代码 bug（用户真实）
- **原始提示词**：`把刚才那段代码里的bug找出来修好，不要改动其他部分，只修复bug。`
- **理想结果**：基于会话中贴出的代码，精准定位 bug 并只修改有问题的行，其余逻辑和格式完全不动
- **隐藏陷阱**：遗忘上下文、凭空生成相似但不同的代码；修复不存在的 bug；顺手重构变量名和整体结构
- **关键约束**：依赖会话上下文、最小修改（只修 bug）

### C11 请假邮件（用户真实）
- **原始提示词**：`帮我写一封给老板的请假邮件，语气要既尊重又随意，大概200字。`
- **理想结果**：称呼得体、原因清晰，礼貌与口语感之间平衡，字数约 200
- **隐藏陷阱**：语气走极端（"嘿，老板"）；虚构请假理由（如"奶奶生病"）；正文超 350 字
- **关键约束**：语气平衡、不虚构理由、字数约 200

### C12 量子纠缠通俗解释（用户真实）
- **原始提示词**：`解释一下量子纠缠，用小学生能听懂的话，100字以内。`
- **理想结果**：用简单比喻（如双胞胎心灵感应）给出概念，100 字内，无术语
- **隐藏陷阱**：混入"叠加态""波函数坍缩"等术语；比喻过于抽象（"薛定谔的猫"）；超字数
- **关键约束**：受众=小学生、100 字内、零术语

### C13 链接文章总结与反驳（用户真实）
- **原始提示词**：`总结一下这个链接里的文章核心观点，并且反驳它。 https://example.com/article/ai-future`
- **理想结果**：真实访问链接（或明确说明无法访问），提炼核心观点，给出有理有据的反驳
- **隐藏陷阱**：无法访问网页却不说明，仅凭 URL 关键词编造文章内容与反驳
- **关键约束**：能力边界诚实——做不到要明说，不得虚构

## 统计

- 总计：13 条（我拟 8 + 用户真实 5）
- 覆盖失败模式：目标模糊、无输出格式、约束遗漏、超范围扩展、噪声、指代不明、多任务、隐含假设、**虚构内容（新增）**、上下文依赖（新增）、能力边界不诚实（新增）
